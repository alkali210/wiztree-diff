# 使用说明

## 导入与范围

- 顶栏两侧分别选择之前、之后的 CSV，或将一个 CSV 拖入对应区域；顺序由使用者决定，不按日期自动调整。
- 拖放目标会高亮，支持 `.csv` / `.CSV`。多文件、非 CSV 或区域外拖放不覆盖已有选择；处理中暂不接受更换文件。
- 选择后点击“开始比较”，不会自动启动。导入、索引和比较在后台运行，可以取消；失败或取消时上一份完整对比仍可用。
- 有导出范围警告时先核对导出根，再确认继续。两侧导出范围不同可能造成假象上的新增或删除。
- “查看之前 / 之后导出根”支持完整根集合分页，每页最多 200 条；摘要只提供前 200 条预览，不截断根总数。

## 目录树与详情

- 展开目录时才读取直接子项，每页最多 200 条；左右共享行模型、选中状态和垂直滚动。读取期间选择其他行或展开另一目录，不会丢弃仍有效的子项；收起目录、切换对比或过滤条件会使旧响应失效。
- “仅变化”保留发生内部变化的祖先，即使目录总量没有变化。
- 树缓存最多 10,000 条记录，通过收起非当前祖先的目录、卸载屏幕外未展开行控制内存。大目录仍可继续翻页；必要时使用“从首页重载”。
- 键盘：上下选择、右箭头展开、左箭头收起、Enter 查看详情。
- 详情显示原路径、类型、字节数、变化量、属性、日期、MFT / 父 MFT、导出计数和驱动器字段等。“完整导出字段”可展开；缺失侧、缺失字段与实际 0 分别显示。

## 全局 treemap

- 始终展示整个对比范围。目录选择、展开及“仅变化”不会缩小图形范围；选择只定位并高亮。
- 可切换之前、之后、差异以及逻辑大小、分配大小；不显示图例。
- 默认最大目录深度为 **0（无限制）**。如需限制，输入正整数并点击“应用”；实际导出根目录算第 1 层，而不是 Windows 路径的绝对层数。
- 有限深度下，达到上限的目录合并成块，仍包含全部后代文件的权重；隐藏文件的高亮定位到可见祖先。深度限制不限制同层直接文件数量。
- 大目录采用嵌套容器，灰色标题栏显示目录名称和文件路径汇总大小，子目录及文件位于其内容区。点击标题选中目录，点击文件块查看文件。
- 小目录可省略不可读的标题装饰，但不会停止无限制遍历或丢弃深层文件。小于一个像素的文件保留几何并合成显示；零权重文件计入数量，但没有面积，仍可在树和详情中查看。
- 导入完成前准备默认“大小 / 无限深度”的之前、之后、差异图；三个模式之间切换不再全量扫描和写入文件几何。分配指标或新深度首次启用时，一次准备该指标、该深度的三个模式，此后继续切换直接使用缓存。未查看的指标不在后台生成；额外深度缓存有界，较旧深度可能在重新访问时再次准备。

### 差异模式

差异模式保留之前的位置、面积、扩展名填充与目录结构，用边框提示修改、删除、类型替换及内部变化，不按变化绝对值重新排布。目录内增长和减少相抵消时仍提示变化。

新增文件没有之前的面积，通过最近可见祖先的虚线框提示；没有之前占用祖先的新增项目通过数量和范围提示列出。完整新增项目可在之后视图或目录树查看。增长、减少、净值分别统计。

## 文件统计

左侧使用程序/代码、图片、视频、文档、压缩包、文本、音频、其他八个大类。主面板按实际扩展名分别展示 `.dll`、`.exe`、`.py` 等，无扩展名独立分组，每页最多 200 行，可浏览完整集合。扩展名颜色与 treemap 中对应文件一致。

关于文件路径汇总、目录导出总量、分配值及硬链接的区别，见[数据口径](data-model.md)。
