# 输入与数据口径

## CSV 输入

- 支持 UTF-8（可有 BOM）的 WizTree 树导出 CSV，可有说明行；必需中文列为“文件名称、大小、分配”。
- 使用完整 Windows 路径和非负十进制原始字节，不接受拆分路径、百分比或未知编码。
- 其余已识别详情列可缺失，也允许缺失尾部可选字段。支持 CRLF、引号、逗号、转义引号和引号内换行。
- 输入字节值及单侧占用聚合必须在 SQLite i64 范围内；差异绝对变化总量可使用完整 u64 范围。错误包含来源、CSV 记录号和字段名；记录号不一定等于文本行号。
- CSV 源文件不修改，也不访问导出记录指向的原始文件。

## 路径匹配与变化

- 按规范化完整 Windows 路径匹配：统一斜杠、保留卷 / UNC 根、移除非根尾斜杠、Unicode lowercase。单侧规范化路径冲突立即报错。
- 大小、分配值和存在性决定变化状态；文件/目录替换单独显示。
- MFT、属性、日期、目录直接汇总和导出计数不冒充大小变化。重命名或移动显示删除加新增，不推断 MFT 连续性。
- 目录总量不变，但后代变化时仍标记内部变化。
- 只连接 CSV 中实际存在的父目录，不补造缺失的中间目录；缺少父目录记录的文件仍进入全局统计。
- 所有字节、增减和 MFT 通过 IPC 使用十进制字符串，前端使用 BigInt 保持精度。

## 占用统计

treemap 和文件分类按实际文件路径汇总，不重复累加目录及其后代，不按 MFT 去重。硬链接的不同路径仍作为不同记录保留。

**分配图不是去重的物理磁盘分区。** 它使用每条文件路径的导出分配值，不猜测空间归属、不缩改单项数值。因此文件路径总和可能与目录导出 aggregate 不同。

目录导出 aggregate、FOLDERSIZE / FOLDERALLOCATED 直接 aggregate 与实际文件路径汇总分别保存，不混用。工作区导出根总量与全局文件路径总量也可能不同。

目录标题栏、边距和边界是结构装饰，不另计占用。子项面积比例在父目录内容区内分配，不能将整张图的像素面积直接视为磁盘占用百分比。差异使用独立布局，按所选指标逐文件路径 `abs(after-before)` 汇总并重排铺满；新增视 before=0，删除视 after=0。目录权重是后代绝对变化之和，不是目录净值的绝对值，避免增长与减少相抵后丢失面积；有限深度折叠仍覆盖全部变化后代。所选指标变化为零的项目不占面积、不命中。全局文件数量不变；差异参与数仅计非零变化文件，权重总量等于增长总量加减少总量，命中值仍为带符号的净增减。

单侧字节总量仍做原有 i64 范围校验；差异的绝对变化合计可能达到两侧总量之和，内部使用无损 u64 权重及固定 8 字节大端 SQLite BLOB 排序/聚合，不因超过 i64 而拒绝原本合法的比较。几何块保留 u64 权重，只有面积计算使用 f64；权重与增减经 IPC 仍为十进制字符串，前端使用 BigInt。

## 扩展名

实际扩展名使用小写末尾后缀，包含点，例如 `.tar.gz` 计入 `.gz`；没有有效后缀时归入无扩展名（如 `README`、`.env`）。左侧八大类是另一个汇总视角，不替代主面板的扩展名列表。

## 大量记录

CSV 在 Rust 中流式解析并分批写入 SQLite，复用解析缓冲；八类固定计数与最多 4,096 种扩展名的工作缓存直接在导入时累积，分批合并到数据库。路径前缀通过最多 4,096 条的工作缓存复用，不把完整路径集合搬入内存。规范化节点按前缀 ID 与文件名精确匹配，原始路径按原样前缀与后缀重建，保留大小写、分隔符及 UNC / 卷根；前缀字典不是目录节点，不补造缺失的祖先。实际父目录 ID 缓存最多 1,024 条，未解析父关系通过 SQLite 临时记录流式补查。

快照成员与原始详情分离：每侧独立保存类型、大小和分配值；完全相同的原始路径与详情只保存一次，不合并不同文件路径，也不按 MFT 去重。比较和分页排序使用紧凑的热数据及规范化文件名字典序排名，详细字段只在有界页面或选中节点需要时读取。树、导出根及扩展名保持分页；完整工作区扩展名预先汇总，所选目录按真实同侧父子关系首次汇总并缓存，文件直接读取自身值。

导入完成前生成默认“大小 / 无限深度”的之前、之后、差异三个完整图像与有界标签、统计；未查看的分配指标和其他深度不提前生成。新指标或新深度首次使用时一次准备三个模式，同一指标与深度内的模式切换只读取现有帧。差异保存独立的非零变化几何；之后图在直接子项权重完全一致的目录内复用之前的局部几何，按新的目录内容区域变换坐标，标题和边距仍按当前视图处理。不同文件权重不能仅因目录净值为零而误判为布局相同。

文件几何以最多 144 条的二进制块保存，使用 f64 坐标；定位索引使用固定页及最多 64 个写入句柄。普通文件不重复保存容器，文件/目录替换及跨快照的真实父节点保留结构语义。空间索引筛选有界块，再对实际矩形和半开边界精确命中，不以像素可见性删掉文件。图形没有前 200 项或 Other 截断。模式切换只读取缓存图像与有界标签，不扫描全部文件或重新写入几何。新深度按指标一次准备三个模式，保留默认深度和两个额外深度，淘汰时复用 SQLite 空闲页；WebView 只保留当前对比、当前深度的最多六个帧，不接收完整树或路径集合。
