# 输入与数据口径

## CSV 输入

- 支持 UTF-8（可有 BOM）的 WizTree 树导出 CSV，可有说明行；必需中文列为“文件名称、大小、分配”。
- 使用完整 Windows 路径和非负十进制原始字节，不接受拆分路径、百分比或未知编码。
- 其余已识别详情列可缺失，也允许缺失尾部可选字段。支持 CRLF、引号、逗号、转义引号和引号内换行。
- 输入字节值及单侧占用聚合保持非负 i64 范围契约；差异绝对变化总量可使用完整 u64 范围。错误包含来源、CSV 记录号和字段名；记录号不一定等于文本行号。
- CSV 源文件不修改，也不访问导出记录指向的原始文件。
- 快照顺序提示仅比较说明行中 `生成由 WizTree <版本> YYYY/M/D H:M:S` 或 `Generated by WizTree <版本> YYYY/M/D H:M:S` 标注的有效导出时间；支持未补零的月、日与时间，并验证日期、闰年及时间范围。比较说明行的当地时间，不猜测时区、文件名时间、CSV 文件修改时间或记录日期。缺失、格式不支持或日期无效均不影响导入，只是不作顺序判断。
- 仅“之前”导出时间严格晚于“之后”时，比较摘要携带可选 `orderWarning`（`beforeTime` / `afterTime`，规范化为 `YYYY-MM-DD HH:mm:ss`）。它是非阻断提示，与需要确认的导出范围 `warnings` 分离；不改变两侧身份、增减方向或统计范围。

## 路径匹配与变化

- 按规范化完整 Windows 路径匹配：统一斜杠、保留卷 / UNC 根、移除非根尾斜杠、Unicode lowercase。单侧规范化路径冲突立即报错。
- 大小、分配值和存在性决定变化状态；文件/目录替换单独显示。
- MFT、属性、日期、目录直接汇总和导出计数不冒充大小变化。重命名或移动显示删除加新增，不推断 MFT 连续性。
- 目录总量不变，但后代变化时仍标记内部变化。
- 比较树与 treemap 只连接两侧 CSV 并集中实际存在的直接父节点，不补造缺失的中间目录。单侧导出根和目录统计另检查该侧成员及目录身份；缺少父目录记录的文件仍进入全局统计。
- 所有字节、增减和 MFT 通过 IPC 使用十进制字符串，前端使用 BigInt 保持精度。

## 占用统计

treemap 和文件分类按实际文件路径汇总，不重复累加目录及其后代，不按 MFT 去重。硬链接的不同路径仍作为不同记录保留。

**分配图不是去重的物理磁盘分区。** 它使用每条文件路径的导出分配值，不猜测空间归属、不缩改单项数值。因此文件路径总和可能与目录导出 aggregate 不同。

目录导出 aggregate、FOLDERSIZE / FOLDERALLOCATED 直接 aggregate 与实际文件路径汇总分别保存，不混用。工作区导出根总量与全局文件路径总量也可能不同。

目录标题栏、边距和边界是结构装饰，不另计占用。子项面积比例在父目录内容区内分配，不能将整张图的像素面积直接视为磁盘占用百分比。差异使用独立布局，按所选指标逐文件路径 `abs(after-before)` 汇总并重排铺满；新增视 before=0，删除视 after=0。目录权重是后代绝对变化之和，不是目录净值的绝对值，避免增长与减少相抵后丢失面积；有限深度折叠仍覆盖全部变化后代。所选指标变化为零的项目不占面积、不命中。全局文件数量不变；差异参与数仅计非零变化文件，权重总量等于增长总量加减少总量，命中值仍为带符号的净增减。

单侧字节总量仍做 i64 范围校验；差异的绝对变化合计可能达到两侧总量之和，内部使用 checked u64 排序与聚合，不因超过 i64 而拒绝原本合法的比较。只有面积计算使用 f64；权重与增减经 IPC 仍为十进制字符串，前端使用 BigInt。

## 扩展名

实际扩展名使用小写末尾后缀，包含点，例如 `.tar.gz` 计入 `.gz`；没有有效后缀时归入无扩展名（如 `README`、`.env`）。左侧八大类是另一个汇总视角，不替代主面板的扩展名列表。

## 大量记录

CSV 在 Rust 中流式解析，复用记录、规范化与冷字段编码缓冲。一份连续节点数组保存规范化路径并集；前缀与文件名使用分块 arena 引用，构建期借用键哈希查找并精确比较，不将哈希当作路径身份。原始路径保留原样前缀和后缀，保持大小写、分隔符及 UNC / 卷根；前缀字典不是目录节点。

两侧成员分别保存类型、大小和分配值；完全相同的原始路径与详情跨侧共享。详情使用缺失位图和长度编码的 UTF-8 冷记录，不逐行保存或解析 JSON；MFT 保留任意长度的规范化十进制文本。硬链接计数按同侧卷与 MFT 分组，仅供详情使用，不合并路径或占用。

之后快照导入时即计算匹配节点的直接状态；完成后确定删除项、补实际父关系、验证层级与导出范围，并自底向上汇总内部变化、目录导出计数和文件路径权重。发布后释放构建期字典与工作缓冲，收紧不再增长的数组。连续父子区间保持目录优先与规范化名称顺序；仅变化使用紧凑子项索引。目录 CSV aggregate 和 treemap 文件路径聚合分别保留。

树、导出根及扩展名每页最多 200 条；游标绑定比较、父节点、侧、指标或过滤范围及真实排序键。八类与完整工作区扩展名在导入期累积；所选目录仅遍历同侧实际目录，按需汇总并用 16 MiB 字节预算缓存排序结果，淘汰后重算仍保持游标一致。文件直接读取自身统计。

treemap 不参与导入发布前置条件，只按当前指标、模式及深度计算一个布局。差异按独立非零变化几何绘制；之后图在直接子项权重一致的目录内复用之前分割，经当前内容区变换坐标，标题和边距仍按当前侧处理。必要的之前容器参考只在计算期间存在，不生成之前 PNG 或完整帧。文件/目录替换及并集容器中的自身文件使用独立内部叶身份，公共节点 ID 不变。

当前布局在 Rust 中保留完整 f64 矩形、紧凑节点定位与平衡空间索引；先筛选候选块，再按实际矩形及半开边界精确命中，不以像素可见性删掉文件。图形没有前 200 项或 Other 截断。布局、当前 PNG 和有界标签只驻内存；重型计算串行且可取消，最多保留正在展示的旧布局与请求的新布局，前端释放已替换或迟到的句柄。命中和高亮针对 layoutId，不隐式生成另一份图；旧比较或布局不能复用到新会话。WebView 不接收完整几何、树或路径集合。
